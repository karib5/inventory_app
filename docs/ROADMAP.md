# Development Roadmap

1. Foundation: companies, users, roles, authentication, tenant isolation
2. Inventory: locations, products, stock in/out, movement history
3. UI: login, dashboards, inventory screens, admin screens
4. Barcode/QR: label generation and scanning
5. Real-time: WebSockets + Redis Pub/Sub
6. Audit logs and reporting
7. Automated tests and security hardening
8. Docker production deployment, backups, monitoring
